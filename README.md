Brand Identity Design - Logo Creation

This project was completed as part of my **Graphic Design Internship** at **Oasis Infobyte**. 

## 📌 Project Overview
The task was to create a unique and professional brand identity. I designed a circular minimalist logo for a book-cafe theme named **AURA CAFE**.

## ☕ Design Concept: "A Fresh Brew of Stories"
The logo beautifully merges two main elements to reflect the cafe's cozy theme:
* **An Open Book:** Represents the love for reading, literature, and stories.
* **A Steaming Coffee Cup:** Symbolizes warmth, fresh brew, and comfort.
* **Typography:** Clean, elegant text arranged in a circular path for a balanced, modern look.
